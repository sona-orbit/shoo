# Shoo! Stickers

Website for **Shoo** — a hand-drawn sticker book for your Mac desktop. Click a sticker and the windows you picked shoo away; click again and they come back.

Served by GitHub Pages at https://sona-orbit.github.io/shoo/

- Home, support and privacy pages in English, 繁體中文, 简体中文, 日本語, 한국어 and ไทย
- Static HTML and CSS with a little vanilla JavaScript; no build step on this repository
- Contact: sona.orbit.hi@gmail.com
